# Aula Libre

Sitio web estatico de Aula Libre, publicado en Netlify.

## Estructura

- `index.html`: contenido principal del sitio.
- `styles.css`: estilos visuales.
- `script.js`: interacciones basicas.
- `assets/`: imagenes, logos y fuentes.

## Publicacion

El sitio puede conectarse a Netlify desde GitHub. Como es una pagina estatica, no requiere comando de build; la carpeta de publicacion es la raiz del repositorio.
